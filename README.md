# Expense Tracker App

## Describtion

A tracker app built with HTML, CSS and JS. It helps users monitor their finance by tracking income, expenses, and total balance

## Features

Input descriptions and amounts (positive values for income, negative values for expenses).

**Storage:**

Auto transaction saving through browser using localStorage.

**Color:**

Green for profits and red for bills.

## Setup

Clone this repository folder to your machine.
Open index.html inside any browser.
Run with GO LIVE in VS Code.

## Tech Used

HTML, CSS & JS
